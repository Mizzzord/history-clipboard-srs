# Сохранять текст при копировании

**User Story:** Как пользователь, я хочу, чтобы скопированный в других приложениях текст автоматически попадал в историю, чтобы быстро вернуться к нему позже.

**Связь с ТЗ:** [FR-01, FR-02, FR-03, FR-08, NFR-03](https://github.com/Mizzzord/history-clipboard-srs/wiki/Техническое-задание#21-сбор-истории).

## Критерии приёмки

- [ ] При включённом сборе текст, скопированный из другого приложения, появляется в истории не позднее 2 секунд.
- [ ] Пустой текст не сохраняется; два последовательных одинаковых копирования дают одну запись.
- [ ] После промежуточного другого текста повторное копирование прежнего текста создаёт новую запись.
- [ ] Сохраняются полный текст и локальное время копирования; запись свыше 1 МиБ не принимается с видимым сообщением.
- [ ] При паузе новые копирования не сохраняются, после возобновления сохраняются снова.
- [ ] При недоступности системного буфера выводится сообщение, сохранённая история доступна.

**Метка:** `enhancement`.
