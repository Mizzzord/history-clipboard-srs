# Сохранять историю между запусками

**User Story:** Как пользователь, я хочу, чтобы история оставалась доступной после закрытия приложения, чтобы не терять нужные фрагменты текста.

**Связь с ТЗ:** [FR-09, FR-10, NFR-01, NFR-02, TEC-01, TEC-02, TEC-03](https://github.com/Mizzzord/history-clipboard-srs/wiki/Техническое-задание#23-хранение).

## Критерии приёмки

- [ ] После штатного завершения и нового запуска записи и порядок восстанавливаются.
- [ ] При добавлении 501-й записи остаются 500 новых, самая старая удалена.
- [ ] При повреждении хранилища пользователь видит ошибку, файл не перезаписывается автоматически.
- [ ] На Windows 10/11 и macOS 12+ история хранится в профиле пользователя и не отправляется по сети; полный текст не попадает в журналы.
- [ ] Установка и сценарии приёмки выполнены на Windows 10/11 x64 и macOS 12+ Apple Silicon/Intel при не менее 2 ГБ ОЗУ, 300 МБ свободного места для установки и дополнительных 600 МБ для истории.
- [ ] При первом запуске показано предупреждение о чувствительных данных и описаны пауза и очистка.

**Отчёт о реализации:** [Выполненные проверки и ограничения приёмки](https://github.com/Mizzzord/history-clipboard-srs/blob/main/docs/ACCEPTANCE.md). Наличие реализации не заменяет проверку каждого критерия на заявленных ОС.
