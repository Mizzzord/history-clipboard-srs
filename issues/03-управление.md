# Повторно копировать и удалять записи

**User Story:** Как пользователь, я хочу вернуть выбранный фрагмент в буфер и удалить ненужные записи, чтобы повторно использовать текст и контролировать свою историю.

**Связь с ТЗ:** [FR-06, FR-07, UI-01, UI-03](https://github.com/Mizzzord/history-clipboard-srs/wiki/Техническое-задание#22-просмотр-и-управление).

## Критерии приёмки

- [ ] «Скопировать» помещает полный текст выбранной записи в системный буфер; он вставляется в другое приложение без изменения.
- [ ] Повторное копирование из истории само по себе не создаёт новую запись.
- [ ] Удаление одной записи убирает только её, в том числе после перезапуска.
- [ ] Очистка всей истории требует подтверждения; отмена оставляет данные, подтверждение удаляет их и после перезапуска.
- [ ] Кнопки действий доступны с клавиатуры, фокус видим.

**Метка:** `enhancement`.
