# Приёмка History Clipboard 1.0.0

Дата проверки: 30 сентября 2026 года. Исходные требования: [Техническое задание](../Техническое-задание.md).

Продукт реализован, самостоятельные сборки доступны в [релизе 1.0.0](https://github.com/Mizzzord/history-clipboard-srs/releases/tag/v1.0.0). Полная приёмка всех заявленных версий ОС остаётся отдельным этапом: GitHub Windows runner использует Windows Server, а минимальные Windows 10/11 и macOS 12 в этой сессии не проверялись.

## Выполненные проверки

- **23 общих автоматических теста** проверяют правила истории, точность Unicode/CRLF/пробелов, UTF-8 лимит, поиск, порядок при изменении часов, ограничение 500 записей, сохранение удаления, повреждённые базы, явное восстановление, транзакционный откат и параллельное чтение/запись SQLite.
- Проверки интерфейса в Avalonia Headless: переход к поиску с клавиатуры, очистка запроса, копирование без потери выбора, исходный фокус на отмене и Escape в подтверждении, сохранение Unicode-пар и CRLF при разбиении длинного текста.
- **Настоящий буфер macOS** в локальной упакованной arm64-сборке: семь сценариев — точный текст, последовательные повторы, А → Б → А, пустое значение, файлы с текстовым представлением, граница 1 МиБ и превышение на один байт, продолжение после отклонения.
- Измеренные задержки от завершения `pbcopy` до появления в SQLite: **0,062–0,328 с** в выполненных прогонах; после более минуты со свёрнутым окном — максимум **0,328 с**, пять принятых копирований. Это результат конкретного прогона, а не измерение на всех компьютерах.
- **Настоящий интерфейс macOS arm64**: первый запуск и предупреждение, пустая история, поиск с кириллицей и разным регистром, отсутствие результатов, пауза и возобновление, копирование, удаление одной записи, отмена полной очистки, сохранение истории после перезапуска.
- Просмотр записи **1 048 576 байт**: интерфейс отвечает, части переключаются, кнопка и Cmd+Enter копируют исходный текст целиком. Сравнение результата `pbpaste` с SQLite подтвердило точное совпадение; число записей осталось прежним.
- На macOS включённый сбор объявляет пользовательскую активность через NSProcessInfo, чтобы избежать App Nap. Обычный сон компьютера разрешён; на паузе и при закрытии активность снимается. Проверка повторена сразу после первого запуска и после длительного свёрнутого состояния.
- Повреждение отдельной QA-базы: приложение показало ошибку и остановило сбор; содержимое файла до восстановления не изменилось. После явного подтверждения создана пустая база, резервная копия совпала с исходным повреждённым файлом, сбор остался на паузе.
- Проверены SHA-256, целостность ZIP, формат Windows PE x64 GUI, архитектуры Mach-O, ad-hoc подписи обоих `.app`. Максимальный минимум ОС у native Mach-O библиотек — 11.0, минимум пакета — macOS 12.0. Это проверка формата, не запуск на macOS 12.

## Матрица платформ

| Платформа | Среда и покрытие |
| --- | --- |
| macOS Apple Silicon | Локальная macOS 27 arm64: полный описанный native/UI прогон. CI macOS 14 arm64: общий набор, native-адаптер и self-test готового файла |
| macOS Intel | CI macOS 15 Intel: общий набор, native-адаптер и self-test готового файла. Интерактивный GUI на Intel не проверялся |
| Windows x64 | CI Windows runner: общий набор, настоящий Win32-буфер, уведомления, Unicode, последовательные повторы, собственное копирование, файловые форматы, блокировка буфера; self-test готового `.exe`. Интерактивный GUI на Windows 10/11 не проверялся |

В наборе 25 тестов: 23 общих и по одному native-тесту для Windows/macOS. Native-тест другой платформы пропускается. На обычном локальном запуске оба native-теста отключены; они меняют системный буфер и включаются переменной `HISTORY_CLIPBOARD_NATIVE_TESTS=1` только в одноразовом тестовом окружении.

Результаты CI и его точная среда: [Build and verify desktop packages](https://github.com/Mizzzord/history-clipboard-srs/actions/runs/36657469415). Функциональный код сборок соответствует ревизии `3ecd2ab`; последующие изменения документации не меняют приложение.

## Ограничения и поставка

- Нет сертификатов Windows Authenticode / Apple Developer ID и нотариализации Apple. Mac-пакеты имеют ad-hoc подпись.
- Windows 10/11, macOS 12, работа при 2 ГБ ОЗУ и интерактивный GUI на Intel/Windows требуют дополнительной приёмки в соответствующих средах.
- 2 октября 2026 года TEC-01 согласован с руководством: 300 МБ для установки и дополнительно 600 МБ для истории. Это исправление требования к дисковому пространству; результаты проверок продукта от 30 сентября не изменены.
- Быстрые промежуточные копирования, уже заменённые до чтения, невозможно восстановить из текущего системного буфера.
- История и резервные копии не зашифрованы. Удаление записи не обеспечивает гарантированное стирание следов на носителе.
- Проверки выполнялись в отдельных `artifacts/qa-*` папках. Личные тексты пользователя не включены в репозиторий, отчёты или сборки; исходный текст системного буфера восстановлен после остановки QA-сбора.

ZIP содержит пользовательскую инструкцию и лицензии сторонних компонентов. В Windows `.exe` лицензии также встроены как ресурсы. Релиз содержит ZIP для трёх архитектур, отдельный `.exe`, манифест и SHA-256.
