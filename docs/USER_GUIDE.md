# History Clipboard 1.0

## Запуск

Windows x64: распакуйте архив и запустите `HistoryClipboard.exe`. Установка Python, .NET или других компонентов не требуется. Приложение не требует прав администратора. Сборка не подписана Authenticode, поэтому Windows может показать предупреждение о неизвестном издателе.

macOS: выберите архив `osx-arm64` для Apple Silicon (M1 и новее) или `osx-x64` для Intel, распакуйте и перенесите `History Clipboard.app` в «Программы». Сборка имеет локальную ad-hoc подпись, но не имеет Developer ID и нотариализации Apple. Для загруженного из интернета приложения macOS может потребовать подтверждение открытия в «Системные настройки → Конфиденциальность и безопасность». Не отключайте защиту системы целиком.

## Работа

1. При первом запуске прочитайте предупреждение и нажмите «Понятно, начать».
2. Скопируйте текст в любом другом приложении. При включённом сборе он появится в истории.
3. Введите часть текста в поиск; регистр не имеет значения, включая кириллицу.
4. Выберите запись слева. Справа появится текст и время добавления. Очень длинные записи доступны по частям: используйте «Предыдущая часть» и «Следующая часть». Кнопка «Скопировать» всегда копирует весь исходный текст, независимо от открытой части.
5. Нажмите «Скопировать» и вставьте текст в нужном приложении. Новая запись от этого действия не создаётся.
6. «Пауза» останавливает сбор; просмотр, поиск и управление остаются доступны.
7. «Удалить» удаляет выбранную запись. «Очистить историю» удаляет все записи после подтверждения.

Закрытие окна завершает приложение. Свёрнутое приложение продолжает сбор. Автозапуск и системный трей в MVP не входят.

Клавиатура: Tab / Shift+Tab — переход между элементами; стрелки — выбор в списке; Ctrl+F на Windows или Cmd+F на macOS — поиск; Ctrl+Enter / Cmd+Enter — копирование полного текста; Delete в списке — удаление записи; Escape — очистка поиска. В диалоге удаления исходный фокус находится на «Отмена».

## Правила истории

- Сохраняется только обычный текст, без оформления. Изображения и файлы не собираются.
- Старое содержимое буфера при запуске и текст, скопированный на паузе, не добавляются задним числом.
- Последовательность А → А даёт одну запись; А → Б → А — три.
- Пустая строка игнорируется, пробелы и переводы строк сохраняются без обрезки.
- Время записи — время обнаружения изменения с локальным часовым поясом. Порядок определяется добавлением, а не часами компьютера.
- Максимум 500 записей. При добавлении 501-й самая старая удаляется.
- Максимум 1 МиБ UTF-8 на запись. Более длинный текст не обрезается и не сохраняется; появляется сообщение.
- На macOS текущая версия буфера проверяется каждые 250 мс. Если текст заменён несколько раз между чтениями, промежуточные значения уже могут быть недоступны. Спящий компьютер и период недоступности буфера не входят в гарантию задержки.

## Данные и ошибки

Windows: `%LOCALAPPDATA%\HistoryClipboard`.

macOS: `~/Library/Application Support/HistoryClipboard`.

История находится в `history.db`, признак прочитанного предупреждения — в `settings.json`. Приложение не отправляет тексты по сети и не записывает их в журналы. История не зашифрована; в ней могут находиться пароли и другие чувствительные данные.

При ошибке доступа к буферу приложение показывает сообщение и повторяет попытки; сохранённая история остаётся доступна. При ошибке хранилища сбор останавливается. «Повторить открытие» пытается открыть исходные данные без их замены. «Начать новую историю» требует подтверждения, сохраняет старые файлы в резервной папке и создаёт пустую базу. Резервная папка также содержит личные данные и не удаляется при очистке новой истории.

Удаление истории не очищает системный буфер и не обещает гарантированного уничтожения следов данных на носителе.

Для установки рекомендуется не менее 300 МБ свободного места, для максимально заполненной истории — дополнительно 600 МБ. Исходные 100 МБ из ТЗ не покрывают 500 записей по 1 МиБ и служебные данные. Минимальную ОС и факт проверки конкретной сборки смотрите в [отчёте о приёмке](https://github.com/Mizzzord/history-clipboard-srs/blob/main/docs/ACCEPTANCE.md): наличие файла сборки не означает проверенный запуск на каждой версии Windows/macOS.
