# History Clipboard

Учебный проект: техническое задание на настольный менеджер истории буфера обмена для текста.

Приложение должно сохранять скопированный текст, показывать историю, возвращать выбранный элемент в буфер и хранить данные между запусками. Документ задаёт требования и критерии приёмки; реализация приложения в этот этап не входит.

## Документация и задачи

- [Техническое задание](https://github.com/Mizzzord/history-clipboard-srs/wiki/Техническое-задание)
- [Задачи по реализации](https://github.com/Mizzzord/history-clipboard-srs/issues)

## Область MVP

Windows 10/11 и macOS 12 или новее; текстовый буфер обмена; хранение только на устройстве. Изображения, файлы, синхронизация и мобильные платформы не входят в MVP.

Составлено для практической работы по формированию проверяемых требований с использованием GitHub Wiki и Issues.
